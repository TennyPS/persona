# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Личный сайт-визитка Татьяны Коновой (коммерческий директор, ментор предпринимателей). Цель сайта: коротко и честно рассказать, кто она и чем занимается, чтобы предприниматели вышли на контакт. Кто владелец и для чего проект, описано в `profile.md`.

Сборки, линтера и тестов нет. Проверка результата: открыть `index.html` двойным кликом в браузере (без сервера и зависимостей).

## Архитектура

Сайт многостраничный: три HTML-файла с общим `style.css`, JS нет. Ссылки между страницами относительные. Шапка (липкая, меню «Главная · Обо мне · Контакты», `aria-current="page"` на активном пункте) и подвал продублированы в каждом HTML — при изменении меню правь все три файла.

- **`index.html`** — Главная: hero (фото `images/me.jpg`) → коротко обо мне + три цифры → призыв к действию (ведёт на `contacts.html`).
- **`about.html`** — Обо мне: «Обо мне» (путь) → «Факты из жизни» → «Мои принципы» → «Немного о личном» → призыв.
- **`contacts.html`** — Контакты: карточки-ссылки (сейчас только Email) + блок «Как лучше написать» с mailto-шаблоном письма (тема и тело уже закодированы). Telegram, LinkedIn и WhatsApp/Viber закомментированы как TODO, пока нет ссылок. Телефон на сайте не показывать.
- **`style.css`** — все стили: цвета и шрифты в CSS-переменных `:root`; адаптив для телефона — один `@media (max-width: 820px)` в конце файла.
- **`*.md` в корне** (`про-меня`, `факты`, `принципы`, `личное`, `призыв`, `проекты`) — исходные тексты разделов. Они не подключаются к странице автоматически: текст копируется в `index.html` вручную. При правке содержимого раздела держи `.md` и соответствующую секцию в `index.html` синхронными.
- **`profile.md`** — единственный источник фактов о владельце (цифры, карьера, инструменты, языки).
- **`_CLAUDE.md`** — прежняя заметка с теми же правилами проекта; актуальные инструкции здесь.

## Ограничения

- Несколько HTML-страниц + один общий `style.css`, без JS, фреймворков, библиотек и сборщиков; не усложнять структуру (никаких шаблонизаторов и бургер-меню).
- Не выдумывать факты: цифры и достижения брать только из `profile.md`.
- Текст по-русски, от первого лица, тон деловой, но тёплый (факты и цифры, человеческое отношение).
- Дизайн сдержанный: 2–3 цвета, без кричащих оттенков, анимаций и всплывающих окон.

## Известные расхождения

`проекты.md` — остаток прежней персоны («воительница», «Главный акт…»): к Татьяне Коновой не относится и в `index.html` не используется. Не переносить его содержимое на сайт, пока оно не переписано по `profile.md`.
