# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Личный сайт-визитка Татьяны Коновой (коммерческий директор, ментор предпринимателей). Цель сайта: коротко и честно рассказать, кто она и чем занимается, чтобы предприниматели вышли на контакт. Кто владелец и для чего проект, описано в `profile.md`.

Сборки, линтера и тестов нет. Проверка результата: открыть `index.html` двойным кликом в браузере (без сервера и зависимостей).

## Архитектура

Сайт многостраничный: три HTML-файла с общим `style.css` и общим `script.js`. Ссылки между страницами относительные. Шапка (липкая, меню «Главная · Обо мне · Контакты», `aria-current="page"` на активном пункте) и подвал продублированы в каждом HTML — при изменении меню правь все три файла.

- **`index.html`** — Главная: hero (фото `images/me.jpg`) → коротко обо мне + три анимированные цифры (`.stats`, `data-count-to`) → призыв к действию (ведёт на `contacts.html`).
- **`about.html`** — Обо мне: «Обо мне» (путь) → «Факты из жизни» → «Мои принципы» → «Немного о личном» → призыв.
- **`contacts.html`** — Контакты: карточки-ссылки (сейчас только Email, клик копирует адрес в буфер через `data-copy`) + блок «Как лучше написать» с mailto-шаблоном письма (тема и тело уже закодированы). Telegram, LinkedIn и WhatsApp/Viber закомментированы как TODO, пока нет ссылок. Телефон на сайте не показывать.
- **`style.css`** — все стили: цвета и шрифты в CSS-переменных `:root`; адаптив для телефона — один `@media (max-width: 820px)` в конце файла; уважает `prefers-reduced-motion`.
- **`script.js`** — один файл на весь сайт, vanilla JS без зависимостей: scroll-reveal секций (класс `.reveal`/`.is-visible` через IntersectionObserver), анимированные счётчики цифр (`data-count-to`/`data-count-from`/`data-count-suffix`), копирование email в буфер (`data-copy`). Подключается `<script defer src="script.js">` в конце `<body>` каждой страницы.
- **`favicon.svg`** — монограмма «ТК» в акцентном цвете, подключена на всех страницах.
- **`*.md` в корне** (`про-меня`, `факты`, `принципы`, `личное`, `призыв`, `проекты`) — исходные тексты разделов. Они не подключаются к странице автоматически: текст копируется в HTML вручную. При правке содержимого раздела держи `.md` и соответствующую секцию в HTML синхронными.
- **`profile.md`** — единственный источник фактов о владельце (цифры, карьера, инструменты, языки).
- **`_CLAUDE.md`** — прежняя заметка с теми же правилами проекта; актуальные инструкции здесь.

## Ограничения

- Несколько HTML-страниц + один общий `style.css` + один общий `script.js`; фреймворков, библиотек и сборщиков нет и не вводить (никаких шаблонизаторов и бургер-меню).
- JS и анимации — только лёгкий vanilla JS и сдержанные CSS-переходы (появление при скролле, счётчики, копирование в буфер). Без тяжёлых эффектов, автопроигрывающихся каруселей и попапов; новый код должен уважать `prefers-reduced-motion`.
- Не выдумывать факты: цифры и достижения брать только из `profile.md`.
- Текст по-русски, от первого лица, тон деловой, но тёплый (факты и цифры, человеческое отношение).
- Дизайн сдержанный: 2–3 цвета, без кричащих оттенков и всплывающих окон.

## Известные расхождения

`проекты.md` — остаток прежней персоны («воительница», «Главный акт…»): к Татьяне Коновой не относится и в `index.html` не используется. Не переносить его содержимое на сайт, пока оно не переписано по `profile.md`.
