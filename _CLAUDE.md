# Persona

Профиль владельца проекта лежит в profile.md, прочитай его, чтобы понимать, для кого и зачем этот проект.

## Цель
Личный сайт-визитка Татьяны Коновой: коммерческий директор и ментор для предпринимателей. Сайт должен коротко и честно рассказать, кто она и чем занимается, чтобы предприниматели могли выйти на контакт.

## Стек
- Простой HTML, без фреймворков и без сборки.
- Один файл `index.html`: разметка, стили в `<style>`, JS только если действительно нужен.
- Открывается двойным кликом, без сервера и установки зависимостей.

## Тон текста
- Деловой, но тёплый: по делу, с фактами и цифрами, но с человеческим отношением.
- Писать по-русски, от первого лица.

## Дизайн: чего избегать
- Ярких кричащих цветов: сдержанная палитра, 2–3 цвета.
- Анимаций и всплывающих окон.

## Ограничения
- Не выдумывать факты о владельце: цифры и достижения брать только из profile.md.
- Не превращать проект в громоздкий: один файл, без лишней структуры.
- Не тащить фреймворки, библиотеки и сборщики.
